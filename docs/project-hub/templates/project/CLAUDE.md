# CLAUDE.md
あなたは Claude Code。役割と作業IDは起動時に伝えられる。

## 始める時（毎回必ず）
1. .ai/rules.md を読む
2. PROJECT.md と .ai/tasks/<作業ID>.md を読む
3. 自分の役割・作業IDの作業だけする（大きければ小さく分ける）

## 区切りごと・終わる時
- .ai/tasks/<作業ID>.md を更新（状態・変更ファイル・確認結果・残り）
- 「## 手順」の終わった所を [x] にする（無ければ3〜5個書く）
- 自分の変更は自分でテストする

## 権限
確認なしで最後まで進める。削除はゴミ箱へ。
大きな変更の前は Git に保存する。
作業用コピーは Hub が用意する。自分では作らない。
