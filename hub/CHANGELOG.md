# Project Hub の変更の記録

新しいものが上。更新するたびに `package.json` の version と、ここの一番上を同じ番号にする（テストで確かめる）。
番号の付け方：大きな作り直し＝1つ目、機能を足した＝2つ目、直しただけ＝3つ目を上げる。

## 4.20.0（2026-10-02）

- ルートの README を Project Hub の説明に書き換え。前提、`bash hub/setup.sh`、テストの実行方法、同梱 seed の今の中身と導入の挙動、Discord Bot テンプレートが由来であることを書いた。既存の MIT 表示（Discord Bot Portal JP）はそのまま
- hub/README の「はじめて使う時」を、配布元から取得したフォルダの一番上で `bash hub/setup.sh` を実行する手順に変更。特定のリポジトリ・ブランチを指す clone 例は削除
- hub/README に「使う前に知っておくこと」を追加。ローカル専用・認証なし、AI の許可確認の既定、写される設定、自動保存とその限界、手元に残る記録、料金、外へ送る操作の承認について書いた
- ルートの .gitignore に除外を追加：`.env` 系、`.npmrc`、`.dev.vars`、`.claude/settings.local.json`、AI の会話・引き継ぎ・一時作業など。すでに追跡されているファイルは、追加後も追跡されたまま
- 自動 Git 保存（作業前の保存・最初の保存・作業用コピーの取り込み）で、新しく加わる `.env` 系・`.npmrc`・`.dev.vars` 系・`.claude/settings.local.json` をインデックスから外すようにした。`.env.example`・`.env.sample` は例示用として保存する
- すでに追跡されているファイル、Hub を通さず手動でコミットした物、別の名前の秘密ファイルはこの保護の対象外。秘密が入らないことは保証しない
- 自動保存のコミットは、今までどおり確認を出さずに起動し `--no-verify` を付ける（説明に記載）
- 公開用にはHubだけを履歴なしで切り出し、実資料・作業ログ・draftsを含めない。seedを架空のアプリ・サイト・文書・Hubの見本に置換した
- HubのMIT表記（2026 kieiken）を追加し、元テンプレートとxtermの第三者表記を残した
- 初期の役割分担をFable 5.1・Opus 5.5・GPT-6.1-Solに揃え、交代は人の承認後の候補とした。既存の役割設定は書き換えない
- `node scripts/export-public.js`で必要なファイルだけを公開用フォルダへ書き出せる。公開版の変更記録は4.20.0から
- 新規プロジェクトのひな形にも秘密設定・会話・一時作業の除外規則を追加
- テスト用の台帳とAI設定を隔離し、作者の実フォルダやローカルモデルキャッシュに依存せず検証できるようにした
